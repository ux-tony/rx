# 🎨 UI / Дизайн ТЗ: Сайт архитектора

## 1. Общая концепция

Интерфейс сайта должен быть выполнен в стиле минималистичного архитектурного портфолио.

**Референс:** https://zrobim.ru/

---

## 2. Основной принцип

> Интерфейс не должен отвлекать от проектов.  
> Визуальный контент (изображения) — главный элемент сайта.

---

## 3. Характеристики “премиального” UI

### 3.1 Визуал

- крупные изображения проектов (доминируют)
- изображения без рамок и лишних элементов
- минимальное количество UI-обёрток

---

### 3.2 Отступы (spacing)

- увеличенные отступы между блоками
- много “воздуха”
- элементы не должны быть сжаты

---

### 3.3 Типографика

- простой современный шрифт (sans-serif)
- крупные заголовки
- минимальное количество текста
- аккуратные межстрочные интервалы

---

### 3.4 Цветовая схема

- светлый фон (белый / почти белый)
- тёмный текст
- 1 акцентный цвет (используется минимально)

---

### 3.5 UI элементы

- минимальное количество кнопок
- отсутствие визуального “шума”
- избегать стандартного “библиотечного” вида

---

### 3.6 Анимации

- лёгкие hover-эффекты
- плавные переходы
- без сложных или “кричащих” анимаций

---

## 4. Использование UI-библиотеки

В проекте используется Mantine, однако:

- использовать только при необходимости (форма, FAQ)
- не применять дефолтные стили без кастомизации
- избегать ощущения “готового шаблона”

---

## 5. Проекты (ключевой блок)

### Требования:

- изображения занимают основное пространство
- минимальный текст:
  - название проекта
  - тип / категория (опционально)
- сетка:
  - 2–3 колонки на desktop
  - 1 колонка на mobile

---

## 6. Общие требования

- адаптивный дизайн (mobile / tablet / desktop)
- высокая читаемость
- быстрая загрузка
- визуальная чистота

---

## 7. Итоговая формулировка

> UI сайта должен быть минималистичным, современным и визуально “дорогим”, с акцентом на крупные изображения архитектурных проектов, увеличенные отступы и минимальное использование интерфейсных элементов.
